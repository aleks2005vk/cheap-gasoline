# Tools & Utilities

This folder contains utility scripts for data processing and maintenance:

- `append_points.cjs` - Script to append gas station points
- `check_prices.py` - Price checking utility
- `final_append.cjs` - Final data append script
- `gen_append.cjs` - Generate append operations
- `gen_remaining.cjs` - Generate remaining data
- `parse_georgia.cjs` - Parse Georgia gas station data
- `rebuild_points.cjs` - Rebuild points data structure

These scripts are used for data processing and should be run as needed for maintenance.
